# Источник, автор и право на переработку у публикации по статье (CMP-005)

## Зачем

Полный пересказ, перевод и озвучка чужой статьи без права на переработку
нарушают ГК РФ ст. 1270, 1274 (компенсация до 5 млн ₽, блокировка). В студии
«Видео по статье» источник не хранился вовсе, у narrator автор и ссылка в
подписи были, а поля разрешения не было.

## Схема

**narrator, `meta.json` статьи** — поле `license`:

| Значение | Что значит | Полный пересказ в канал |
|---|---|---|
| `own` | статья человека | да |
| `cc-by` | свободная лицензия с указанием автора | да |
| `permission` | автор разрешил | да |
| `none` (по умолчанию) | права нет или неизвестно | нет: только аннотация |

Старые карточки без поля читаются как `none`. Значение вне списка —
ошибка загрузки карточки.

**Студия, настройки выпуска «Видео по статье»** — `source_url` (http/https,
до 500 знаков) и `source_author` (до 200 знаков). По умолчанию пусто.

## Поведение

narrator:

- `telegram.broadcast` для `kind: article` с `license: none` — `TelegramError`
  с подсказкой; отметка об отправке не ставится, mp3 остаётся локально.
- `./narrate bot send <каталог> --annotation` — вместо аудио сообщение:
  заголовок, `summary`, обрезанный до 20 % объёма `source.md` (или
  `script.txt`), автор, ссылка «Оригинал статьи», сноски реестра. Без `url`
  аннотация не уходит.
- `bot unsent` статьи без права пропускает с сообщением, а не обрывает
  рассылку. Рассылка после `synth` печатает ошибку, озвучка не падает.
- Bridge отдаёт `license` в карточке и принимает его в `article-save`;
  платформа (вкладка «Библиотека») — выпадающий список у описания.

Студия:

- Шаг «Публикация» выпуска «Видео по статье» без `source_url` или
  `source_author` — `StudioError`, ничего не отправлено.
- С источником в конец поста дописывается строка `Источник: <автор> —
  [оригинал](<url>)`. Она попадает в неудаляемый хвост подписи (CMP-001):
  при обрезке длинного поста остаётся целиком, рядом со сносками реестра.
- На последнем показанном слайде основного видео строка `Источник: <автор> —
  <url>` идёт полосой внизу кадра, тем же механизмом, что пометки реестра.
  Смена источника сбрасывает сборку видео и шортса.
- В форме настроек студии для статьи — группа «Источник — обязателен для
  публикации».

## Вне рамок

- Серия частями (`split`) наследует настройки, значит и источник; отдельного
  ограничения «не больше N частей без права» нет. Право в студии не
  хранится: студия требует только указать источник.
- Проверка лицензии по странице (CC-метки) — вручную, агент по регламенту
  `app/narrator/CLAUDE.md`.
