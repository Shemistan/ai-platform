# План: вкладка «Моушн» (PRD-026)

Одна ветка `worktree-motion-tab` — модуль связный, по частям не работает.

1. `motion/config.py` — `MotionConfig` поверх `montage.config.load`, `AIP_MOTION_PARALLEL`.
2. `motion/scenes.py` — упаковка слов для промпта, слова ↔ секунды, таймкод
   `ЧЧ:ММ:СС:КК`, slug, csv/txt, zip. Тесты.
3. `motion/agents.py` + `assets/` — пять ролей: промпт, разбор и чистка
   ответа, каркас композиции (CSP, GSAP, `window.__timelines`), проверка кода
   аниматора. Тесты на разбор и сборку.
4. `motion/source.py` — импорт ролика «Монтажа»: жёсткая ссылка, слова
   результата через `edl.build` + `edl.output_words`. Тест на фейковом проекте.
5. `motion/projects.py` — хранение, очередь, этапы, конвейер `make` и `scene`,
   параллельные сцены, рендер, превью, пакет.
6. `motion/service.py` + регистрация в `server.py` (группа «Медиа»).
7. Фейки: `fake_llm` — задачи `motion_*`; `fake_hyperframes` — размер из композиции.
8. Фронт `static/motion/`: проекты, загрузка/импорт, этапы, сцены с превью,
   правка, пакет. JS-тесты на чистые функции.
9. API-тесты пути на фейках; `make demo` руками в браузере.
10. Документы: `context.md`, `user-guide.md`, `configuration.md`, `api.md`,
    `api-routes.md` (гейт), `CHANGELOG`.
11. Проверка на настоящем ролике — если позволит окружение.

## Итог

Сделано всё, кроме п. 11. В песочнице агента сеть закрыта для
`api.anthropic.com` (не работает `claude -p`) и `registry.npmjs.org` (не
ставится HyperFrames). Проверено вместо этого: весь путь на фейках по
настоящему 29-минутному ролику «Монтажа» (его слова переложены на время
результата), каркас композиции — в Chrome, с покадровой перемоткой таймлайна
по сцене «TCP → IP → Ethernet», написанной по контракту аниматора; наложение
альфы ProRes 4444 — ffmpeg-пробой. Первый прогон с настоящими агентами — за
человеком: `make models M=hyperframes`, затем «Моушн» → ролик из «Монтажа».
