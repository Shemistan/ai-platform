# План: выпуски от «собрано» до «опубликовано и посмотрено»

Восемь подзадач, каждая — свой коммит с зелёным `./check` в ветке
`worktree-release-flow`. `./finish` в сессии не прошёл: песочница не пускает
push по SSH в origin — ветку отправляет человек (`./finish`).

1. **board** — `Studio.list` с вниманием, опубликованностью, архивом;
   `GET /api/studio/board`, `POST …/archive`; страница `static/board/`,
   вкладка «Выпуски» со счётчиком в шапке; быстрая публикация с доски.
2. **reuse** — `source` выпуска, 409 на дубликат и `force_new`;
   `POST …/clone`; `studio/cache.py` и кэш в картинках, роликах, озвучке
   (и шортсе); UI: «уже есть выпуск — открыть / создать новый», «Копия».
3. **preflight** — `studio/estimate.py`: ставки по истории задач, оценка
   выпуска; `started_at`/`finished_at` у шагов; `preflight()` и показ в
   выпуске и в форме создания (`POST /api/studio/preflight`); публикация
   проверяет все каналы до отправки.
4. **draft** — настройка `draft`, масштаб сборки на вызов рендера, кнопка
   «Сделать чистовик»; `studio/series.py`: разбивка на части; выжимка
   через LLM; `POST …/split`, `POST …/summary`; фейковая LLM — выжимка.
5. **schedule** — `schedule` и `notify` в `settings.json`; поток
   расписания в studio; `core/notify.py`; раздел «Расписание» во вкладке
   «Настройки».
6. **stats** — `message_id`, `chat`, `members_at_publish` в результатах
   публикации; `studio/stats.py` (getChat, getChatMemberCount, embed-
   страница); `POST /api/studio/stats/refresh`, ручные просмотры; ежедневное
   обновление в потоке расписания; сводка «что работает» на доске.
7. **cleanup** — `core/cleanup.py`: размер областей, удаление старше N
   дней через менеджеры задач, кэш, архивные выпуски; раздел «Уборка» во
   вкладке «Настройки»; ежедневно по флажку.
8. **docs** — README платформы (новые вкладки и настройки, «Что
   проверено»), `aiplatform/smoke.py` и `make smoke`, статусы спеки и плана.
