# План: без лимита слайдов, динамические слайды, ритм 3–5 с

Одна связная задача, одна ветка.

1. `studio/slides.py`: убрать `MAX_SLIDES`; `Slide.sent`, `Slide.kind` и
   данные сцен; разбор фраз; `starts`/`durations` по фразам; ориентир числа
   слайдов по длине текста.
2. `studio/prompts.py`: промпт плана с нумерацией фраз, видами слайдов,
   чередованием и ритмом.
3. `studio/motion.py` (новый): фильтры ffmpeg динамических сцен и
   расписание появления элементов.
4. `studio/render.py`: `image`-слайд — планы по ~4 с с разным движением,
   тезисы растянуты по слайду; динамический слайд — через `motion`.
5. `studio/steps.py`, `studio/service.py`: картинки только у `image`,
   пометки по фразам, сцены с `kind`; UI — вид слайда и «абзац N, фраза M».
6. `fakes/fake_llm.py`: демо-план со всеми видами вперемешку.
7. Тесты, `./check`, сборка демо-видео и просмотр кадров.
