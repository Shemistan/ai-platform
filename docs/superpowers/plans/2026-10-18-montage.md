# План: вкладка «Монтаж» (PRD-020, PRD-021, PRD-022)

Три подзадачи, каждая — своя ветка от `staging`, `./check` и `./finish`.

## 1. Расшифровка (PRD-020) — ветка `worktree-montage`

1. `montage/asr.py`: каталог трёх моделей (репозиторий, ревизия, каталог,
   файлы-признаки), `installed`, `missing`, `public`, argv воркера, разбор
   строк `PROGRESS`.
2. `montage/asr_worker.py`: куски по точкам разреза, Whisper
   (`word_timestamps`, `hotwords`) и Qwen3-ASR + ForcedAligner с возвратом
   пунктуации; тяжёлые импорты — внутри функций.
3. `montage/transcript.py`: слова, `silencedetect` → тишина, точки разреза
   ≤ 5 мин по тишине.
4. `fakes/fake_asr.py`; `montage/compare.py` (WER, латиница, слова в тишине,
   скорость) + `make asr-compare`.
5. `tools/setup-model.sh`: `ASR_IDS`, `install_asr` (окружение mlx-audio
   0.5.8, `hf download --revision`), `AIP_MONTAGE_ASR_PYTHON` в `local.mk`.
6. Тесты: каталог/установленность, разбор вывода, точки разреза, WER,
   сопоставление пунктуации Qwen, fake-воркер.

## 2. Вкладка «Монтаж» (PRD-021)

1. `config.py`, `edl.py` (вырезки + паузы → сегменты, привязка к тишине,
   карта результат→исходник), `sync.py`, `plan.py` (промпты, разбор, правила).
2. `render.py`: сегмент (head/screen/split, грейд, фейды), склейка, финал
   (loudnorm, ASS-субтитры, оверлеи), SRT.
3. `projects.py`: хранение, очередь, конвейер, проверка с кругами исправлений,
   уроки; `service.py`: API, загрузки потоком.
4. `server.py`, `runner.LIMITS["asr"]`, `settings.LIMIT_KINDS`, уборка.
5. Фронт `static/montage/` (список, карточка, подтверждение, правила) +
   JS-тесты; `fake_llm.py` — задачи `montage_*`.
6. Тесты бэкенда на фейках: путь «загрузил → план → подтвердил → mp4»,
   две записи и планы, замечание → урок, ошибки ввода.
7. Документация: карта, user-guide, configuration, api.md, api-routes.

## 3. Моушн-графика (PRD-022)

1. `motion.py` + шаблоны `assets/motion/*.html`, `fakes/fake_hyperframes.py`.
2. Шаг в конвейере, оверлеи в финальном проходе; `make hyperframes`.
3. Тесты на фейке, документация.
