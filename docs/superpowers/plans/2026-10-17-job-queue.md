# План: одна очередь задач `core.jobs` (BE-007)

Каждый шаг — свой коммит с зелёным `./check`; публичный API модулей не меняется.

1. [x] `_work` фото/видео/аудио: пропуск исчезнувшей задачи; тест «отмена +
   forget до воркера» (`tests/test_job_queues.py`).
2. [x] `core/jobs.select/list_args`; `GET …/jobs?limit=&since=` у трёх вкладок,
   без `limit` — 100; тест на `limit=50`-подобную выборку и 400.
3. [ ] `core/jobs.JobQueue`: хранение, восстановление, cancel/wait/forget,
   воркер с GPU-замком и лимитами `runner`, хуки `command/progress/result_path/view`;
   юнит-тесты на фейковой спеке.
4. [ ] Перевести `audio/jobs.py` (самая простая модель: без `models`) на
   `JobQueue`; тесты `test_audio.py` без правок.
5. [ ] Перевести `video/jobs.py`, затем `photo/jobs.py` (upscale — второй
   вид спеки); тесты вкладок без правок.
6. [ ] Перевести `core/tasks.py` (`Tasks`): миграция `<id>.json → <id>/job.json`
   при загрузке (схема задач 2, ADR 0009).
7. [ ] Удалить дубли `_save/_load/_finish/_work`; `keep` истории у всех очередей.
