# Бенчмарк итеративного ревью (ITERATIVE_REVIEW_SPEC R7, PRD-028)

Замеры на машине из `ENVIRONMENT_AUDIT.md` (MacBook Pro M1 Pro, 32 ГБ, macOS 27.0.1,
ffmpeg 7.1.1), фейковые модели (`AIP_BACKEND=fake`: ASR, LLM и HyperFrames — имитации),
ffmpeg настоящий. Фикстура — `tests/test_montage_review_e2e.py`: ролик 150 с
(`testsrc` 640×360 + синус), раскадровка из трёх сцен, субтитры файлами. Числа —
из тестового прогона `make test T="tests/test_montage_review_e2e.py"`; они говорят
о стоимости конвейера (ffmpeg-проходы, файлы), а не о скорости моделей: с
настоящими `claude -p` и HyperFrames к каждому вызову роли и перерисовке сцены
добавится время модели.

## Что измеряется

| Стадия | Что делает | Чем ограничена |
|---|---|---|
| Бандл версии | один проход ffmpeg: прокси 640p, кадры сцен и раз в 10 с, signalstats, ebur128, silencedetect | CPU, длительность ролика |
| Роли-измерители и эвристики | чтение манифестов и бандла, без подпроцессов | мс |
| LLM-роли (4) и судья | вызовы `claude -p` (фейк — мгновенно) | модель |
| Правки манифестов | JSON | мс |
| Пересборка | сегменты из кэша, перерисовка изменённых сцен (фейк HyperFrames — ffmpeg), финальный проход с наложениями, QA (ffprobe + blackdetect/silencedetect/astats) | ffmpeg: ≈ 0,3 × длительность ролика на финал + 3 × длительность сцены на перерисовку |
| Бандл кандидата + повторные замеры | как бандл версии | CPU |
| Сравнение | ffprobe, манифесты, судья | мс + модель |

## Как повторить

```sh
cd app/platform && make test T="tests/test_montage_review_e2e.py -s"   # печатает время каждого теста
cd app/platform && make test T="tests/test_montage_progress.py"        # 100 000 событий и SSE
```

Ограничения честно: GPU-метрик у машины нет (ADR 0012), поэтому «GPU-минуты»
бюджета — минуты тяжёлых процессов; HyperFrames на машине не установлен, сцены
в прогонах рисует фейк (ffmpeg-плашка той же длительности и с альфой), поэтому
время перерисовки настоящих HTML-сцен здесь не измерено.
