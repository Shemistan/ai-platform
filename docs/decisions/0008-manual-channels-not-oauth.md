# 0008. Публикация: Telegram ботом, остальные площадки — ручной пакет вместо OAuth

Записано задним числом (DX-008).

## Контекст

Выпуски уходят в Telegram (основной канал) и на YouTube, TikTok,
Instagram. Telegram Bot API работает по токену бота. API остальных площадок
требуют зарегистрированного OAuth-приложения, проверки приложения
площадкой и хранения refresh-токенов — для локального сервиса одного
человека это недели согласований и секреты, которые надо обновлять.

## Решение

- Тип канала в `channels.json` (`aiplatform/studio/publish.py`):
  `telegram` — `sendVideo` ботом с подписью из шага «Публикация»; токен —
  из переменной окружения канала, в файлы, лог и ответы API не попадает.
- `manual` — пакет для ручной загрузки: `video.mp4`, `title.txt`,
  `description.txt` в `data/studio/projects/<id>/publish/<канал>/`. Человек
  заливает сам и отмечает «Залил» со ссылкой — выпуск считается
  опубликованным (`POST /api/studio/projects/{pid}/uploaded`).
- Интерфейс публикатора не завязан на тип канала: новый тип — новый класс
  без правки сценариев.

## Последствия

- Нет OAuth-приложений, ревью площадок и refresh-токенов.
- YouTube/TikTok/Instagram — ручной шаг человека; статистику по ним
  вносят руками (`POST /api/studio/projects/{pid}/stats`).
- Bot API принимает видео до 50 МБ — это лимит канала `telegram`.

## Когда пересматривать

- Ручная загрузка станет узким местом (несколько выпусков в день на
  площадку).
- Площадка даст загрузку без OAuth-приложения или появится готовое
  одобренное приложение.
