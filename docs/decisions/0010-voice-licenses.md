# 0010. Лицензии движков озвучки и голоса Charon для публикуемых выпусков

Задачи CMP-017 (голос Charon) и CMP-018 (некоммерческие движки). Статус
«предложено»: условия сверены только по файлам на диске; в интернете из
песочницы агента их не проверить. Что сверить человеку — в конце.

## Контекст

Выпуски уходят в канал, а канал можно монетизировать. Значит, лицензия
движка и образца клонируемого голоса должна разрешать коммерческое
использование результата. Что известно из репозитория и с диска
(`/Volumes/External SSD/local_models`, карточки моделей на 2026-10-17):

| Движок | Где сказано | Лицензия | Публиковать |
|---|---|---|---|
| `silero` (v5.5 ru) | `app/narrator/CLAUDE.md`, `voices.py` | CC BY-NC (своего LICENSE рядом с весами нет: `silero/v5_5_ru.pt` без файлов) | нет |
| `fish` (Fish Audio S2 Pro) | `mlx-audio/models--mlx-community--fish-audio-s2-pro-bf16/…/README.md` | `fish-audio-research`: «Non-commercial use: Free», коммерческое — отдельно | нет |
| `higgs` (Higgs TTS 3, по умолчанию у платформы) | `mlx-audio/models--bosonai--higgs-audio-v3-tts-4b/…/LICENSE` | Boson Higgs TTS 3 Research and Non-Commercial; **Creator Use Grant** (разд. II-A) разрешает публиковать и монетизировать контент на своих каналах | да, с упоминанием Boson AI и согласием владельца клонируемого голоса |
| `espeech` (ESpeech-TTS-1 RL-V2) | `ESpeech-TTS-1_RL-V2/README.md` | apache-2.0 | да |
| `moss` (MOSS-TTS v1.5 + Audio Tokenizer) | карточки обеих моделей | apache-2.0 | да |
| `qwen3` (Qwen3-TTS 1.7B) | карточка модели | apache-2.0 | да |
| `chatterbox` (multilingual v3) | карточка модели | mit (в звуке водяной знак) | да |
| `supertonic` (Supertonic 3) | `supertonic3/LICENSE` | BigScience OpenRAIL-M: ограничения по применению, не по коммерции | да |

Условия Creator Use Grant у Higgs (LICENSE, разд. II-A и IV(b)):

- в публикуемом контенте нужно упомянуть «Boson AI's Higgs Audio» в звуке
  или в тексте рядом (описание, подпись), например «This audio was created
  with Boson AI's Higgs Audio — https://www.boson.ai/higgs-audio». Сейчас
  код этого не делает;
- клонировать можно только голос, на образец которого есть права и
  согласие владельца (IV(b)(ii)); для публичного использования согласие
  надо уметь подтвердить.

Образцы клонируемых голосов (`app/narrator/src/narrator/voices/`,
`CLONE_VOICES` в `synth.py`):

- `Shem`, `Shem-v2` — живой голос автора канала, записан им самим: права и
  согласие есть;
- `M1` — вывод Supertonic (OpenRAIL-M): ограничений на вывод для этой
  задачи не видно;
- `Charon` — отрывок дайджеста, озвученного Gemini TTS (`./narrate voice
  charon` пишет его через Gemini API). Это вывод чужого сервиса, и
  клонирует его другая модель. Charon — голос по умолчанию у всех
  клон-движков (`DEFAULT_VOICES`), то есть у выпусков платформы.

Что известно об условиях Gemini API без сети (по памяти, **не сверено**):
в Gemini API Additional Terms of Service Google не заявляет прав на
сгенерированный контент, но запрещает использовать сервис или его вывод
для разработки моделей, которые конкурируют с Google, и отсылает к
Generative AI Prohibited Use Policy (выдача себя за другого и обман
запрещены). Отдельного разрешения клонировать голос из вывода TTS другой
моделью условия не дают. Голос Charon — синтетический, а не голос
реального человека, но это голос из каталога Google.

## Решение (предложено)

1. Движки с некоммерческой лицензией помечены `license_nc` в
   `app/platform/aiplatform/audio/voices.py`: `silero` и `fish`. Шаг
   «Публикация» не отправляет выпуск, озвученный ими (CMP-018, тест
   `NcVoicePublishTest`), и предлагает переозвучить.
2. Higgs остаётся движком по умолчанию: Creator Use Grant разрешает
   монетизируемый контент на своих каналах. Условие гранта — упоминание
   Boson AI в подписи публикуемого выпуска. Пока его нет, это нарушение
   гранта; нужна отдельная задача на строку в хвосте подписи.
3. Голос Charon до проверки условий человеком **не меняется**. Если
   проверка покажет, что клонировать вывод Gemini TTS для публикации
   нельзя (или права на образец не подтвердить для Higgs IV(b)(ii)), то:
   голос по умолчанию клон-движков — `Shem-v2` (свой голос, согласие есть)
   в `DEFAULT_VOICES` narrator и `default_voice` в `voices.py` платформы;
   Charon — только для черновиков (как `license_nc`, но по голосу).
   Альтернатива — озвучивать публикуемый дайджест Gemini TTS напрямую (без
   клонирования): так образец не нужен, действуют только условия Gemini.

## Что проверить человеку

- [ ] Актуальные Gemini API Additional Terms of Service и Generative AI
      Prohibited Use Policy: можно ли использовать аудио Gemini TTS как
      образец для клонирования другой моделью и публиковать результат с
      монетизацией. Ссылки: https://ai.google.dev/gemini-api/terms,
      https://policies.google.com/terms/generative-ai/use-policy.
- [ ] Лицензия Silero v5.5 ru на https://github.com/snakers4/silero-models
      (CC BY-NC 4.0 или другая) и есть ли коммерческая.
- [ ] Лицензия Fish Audio S2 Pro: https://huggingface.co/fishaudio/s2-pro/blob/main/LICENSE.
- [ ] Higgs Creator Use Grant: подходит ли канал под «Digital Creator» и
      какой текст упоминания Boson AI ставить в подпись.
- [ ] После проверки — статус ADR «принято», при запрете Charon — смена
      голоса по умолчанию по п. 3.

## Последствия

- Silero и Fish остаются для черновиков и сравнения; публикация с ними
  падает с понятной ошибкой.
- Пока ADR не принят, публикуемые выпуски звучат голосом Charon. Это
  лицензионный риск: условия Gemini не сверены.
- Нужна задача на упоминание Boson AI в подписи при озвучке Higgs.
