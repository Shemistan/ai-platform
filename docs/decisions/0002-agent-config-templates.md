# Регламент агента: шаблоны .claude/ в репозитории, ставит bootstrap.sh

## Контекст

`CLAUDE.md` опирается на механизм, которого в клоне нет: `.claude/settings.json`
(режим `dontAsk`, sandbox, список сетевых доменов, хук `UserPromptSubmit`) и
`.claude/hooks/preflight.sh` в git не отслеживаются. Свежий клон получает текст
регламента без механизма (DX-010).

Механизм состоит из трёх частей:

1. git-хуки `.githooks/` (запрет коммита агента в `main`, `./check` перед
   коммитом, формат сообщения, запрет push в `main`) — уже в репозитории,
   включаются `sh bootstrap.sh`;
2. проектные настройки агента — `.claude/settings.json` и обёртка
   `.claude/hooks/preflight.sh`;
3. общие хуки агента в `~/.claude/hooks/` — `preflight.sh` (worktree,
   контекст сессии) и PreToolUse-guard `guard.py`. Их ставит
   `install-global.sh` скелета ai-god-mode, это вне этого репозитория.

Варианты для части 2:

- **Коммитить `.claude/settings.json` и хуки как есть.** Так сделано у
  `app/narrator/.claude/settings.json` — профиль, который *сужает* права
  контент-агентов. Но корневой файл права *расширяет* (`dontAsk`, `Bash`
  без вопросов, сетевые домены): любой merge в `main` и `git pull` молча
  меняли бы права агента на каждой машине. Список доменов к тому же
  машинный (корпоративный хост автора).
- **Только описать в README.** Ничего не копируется, текст устаревает
  относительно настоящих файлов.
- **Шаблоны в репозитории, установка — `bootstrap.sh`.**

## Решение

Шаблоны лежат в `tools/claude/` (`settings.json`, `hooks/preflight.sh`) и
отслеживаются git. `sh bootstrap.sh` в главном checkout копирует их в
`.claude/`, если файлов там ещё нет; существующие не перетирает, а при
расхождении с шаблоном печатает команду `diff`. В worktree `.claude/` не
ставится — сессии worktree берут его из главного checkout. Нет общих хуков
в `~/.claude/hooks/` — `bootstrap.sh` предупреждает и ссылается на README
(раздел «Регламент агента»).

`.claude/` остаётся вне git: там же `worktrees/` и `settings.local.json`.

## Последствия

- Свежий клон: `sh bootstrap.sh` + общие хуки из скелета → работают
  preflight, guard и git-хуки. Без общих хуков preflight блокирует промпты
  с подсказкой, git-хуки работают.
- Поменять права агента для всех — правка шаблона через PR; на машине она
  появится, когда человек сравнит `diff` и скопирует файл сам. Права не
  расширяются побочным эффектом `git pull`.
- Две копии (шаблон и `.claude/`) могут разойтись; `bootstrap.sh`
  показывает расхождение при каждом запуске.
- Если однажды решим коммитить `.claude/settings.json` напрямую — новый
  ADR, этот в `заменено`.
