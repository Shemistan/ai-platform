# Источники дайджеста, версия 2

Статус: внедрено 2026-10-15, пересмотр — после 2026-10-22.

## Почему

Разбор 33 выпусков (261 событие) с 1 сентября по 14 октября:

- в главной рубрике 66 из 84 событий — GitHub Changelog (26), ClickHouse
  (20), Kubernetes (11), PostgreSQL News (9). «ClickHouse выпустил патчи
  для четырёх веток» — пять раз за десять дней;
- рубрика «Инженерные блоги» — 8 событий за 33 выпуска, из них 6 от
  Cloudflare; Netflix 0 из 12 разобранных, Stripe 0 из 7;
- YouTube: 15 из 17 каналов не собирались (лента канала отвечает 404/500);
- Hacker News и Lobsters: 645 разобрано, в выпуск — 24.

Причины две: формула важности давала посту поставщика из стека 0,40 балла
заранее, а источников, которые пишут разборы, почти не было. Формулу
поправила версия 2 (спек `2026-09-23-news-digest-design.md`, «Оценка
важности»), ленту YouTube — запасная лента плейлиста загрузок. Этот файл —
про источники.

**Уязвимости — структурированные базы, не пересказ:**

- `go_vulndb` — Go Vulnerability Database (vuln.go.dev, JSON API), вид
  `govuln`: последние 30 изменённых записей, только проверенные командой Go
  (`review_status` = REVIEWED). Покрывает и стандартную библиотеку.
- `ghsa_go` — GitHub Advisory Database (api.github.com/advisories), вид
  `ghsa`, экосистема go, от medium, только пакеты из списка `packages`
  (параметр `affects`). Без списка экосистема Go — десятки уязвимостей
  конечных приложений в день (Vikunja, Nginx UI), и 30 записей ленты
  покрывают четверть часа. Список — библиотеки типичного Go/backend-
  сервиса: x/, gRPC, драйверы баз и очередей, HTTP-фреймворки, JWT,
  контейнеры, Kubernetes, observability. Пополнять по мере надобности.
- `ghsa_actions` — то же для GitHub Actions, от high, без списка: записей
  несколько в месяц, а важны как раз неожиданные атаки на цепочку поставок.
- `kubernetes_cve` — официальная лента CVE Kubernetes.

В аннотации материала — серьёзность и EPSS. vuln.go.dev sandbox агента не
открывает: собирает `make news` в обычном терминале.
