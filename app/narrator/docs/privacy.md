# Бот озвучек: какие данные хранятся и как их удалить

Коротко: бот помнит только номер вашего чата и дату подписки. Команда
`/stop` отписывает и сразу удаляет эту запись.

## Что хранится

- **Номер чата** (chat_id) — внутренний номер Telegram, по которому бот
  присылает сообщения.
- **Дата подписки.**
- **Метка ссылки**, по которой вы подписались (`t.me/<бот>?start=<метка>`) —
  например, метка поста, из которого вы пришли. Это метка выпуска, а не
  сведения о вас; если подписались без ссылки, её нет.

Имя, фамилия, @username, текст ваших сообщений и номер телефона не
сохраняются. Бот видит имя в момент, когда вы пишете ему, но никуда его не
записывает.

## Зачем

Чтобы присылать вам озвучки статей: mp3 и короткое описание. Для рекламы и
передачи третьим лицам данные не используются.

Владелец бота видит только общие числа: сколько человек подписалось по
ссылке из какого поста и какая доля подписчиков осталась через 7 и 30 дней.
Для этого после отписки остаётся строка «подписка с <даты> по <дату>, метка
ссылки» — без номера чата и без чего-либо, что связывает её с вами.

## Где и сколько

Запись лежит в файле на компьютере владельца бота, доступ к файлу есть
только у него. Хранится, пока вы подписаны. После `/stop` или блокировки
бота запись удаляется сразу (остаётся только обезличенная строка для общих
чисел, см. выше).

Сами сообщения переписки хранит Telegram по своим правилам; бот их не
сохраняет.

## Как удалить

- Отправьте боту `/stop` — бот ответит «Отписал и удалил ваши данные».
- Или заблокируйте бота — запись удалится, когда бот в следующий раз
  попробует вам написать.
- Если бот недоступен, напишите владельцу бота: он удалит запись командой
  `./narrate bot forget <chat_id>`.
